# Security

Report a vulnerability in these plugins privately through
[GitHub private vulnerability reporting](https://github.com/kadet-hub/backstage-plugins/security/advisories/new).
Do not open a public issue for it. Without a GitHub account, write to
security@kadet-hub.org.

A vulnerability in a recipe or generator belongs to
[kadet-hub/recipes](https://github.com/kadet-hub/recipes/security) or
[kadet-hub/registry](https://github.com/kadet-hub/registry/security). A
vulnerability in Backstage itself belongs to
[backstage/backstage](https://github.com/backstage/backstage/security).

## Supported versions

Fixes go into the newest release of each package. Until a package is
published to npm, fixes go into `main`.

## Handling

kadet-hub has one maintainer, so reports are handled on a best-effort
basis, without a service level or a promised response time. A fixed
vulnerability is published as a
[GitHub security advisory](https://github.com/kadet-hub/backstage-plugins/security/advisories)
with the affected versions and a CVSS score.
